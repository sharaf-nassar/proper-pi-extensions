# proper-pi-extensions

A collection of local [pi](https://github.com/badlogic/pi-mono) extensions.

## Extensions

| Extension | Purpose |
| --- | --- |
| [proper-llm-router](./proper-llm-router/) | Routes each session's first task to an appropriate model. |

Each extension is a self-contained package in its own top-level directory.
Install one from this checkout with its directory path:

```bash
pi install ./proper-llm-router
```
